# How To Use

> [!NOTE]
> <b>Extension is designed for a mass audience, so uploading a video differs little from the standard process</b>

<b>1. Install extension from Chrome Web Store</b>

<b>2. Subscribe to our two channels:</b>
<ul>
  <li><a href="https://editingnews.com/channel">@editingnews</a></li>
  <li><a href="https://editingnews.com/rett">@lexuof</a></li>
</ul>

<b>3. Go to [Studio upload page](https://www.tiktok.com/tiktokstudio/upload?from=webapp)</b>

<b>4. Ensure that the extension badge in the top-right corner displays "Editing Enhancer"</b>

<b>5. Select one of the available methods:</b>
  <ul>
    <li>Enhanced Method</li>
    <li>HQ Method</li>
    <li>Standard Method</li>
  </ul>

<b>6. Upload your video</b>
